# Glossary

The design is in Portuguese and the code is in English. Some Portuguese words cover more than one concept, so use these names.

| Portuguese                   | Code name              | Meaning                                         |
| ---------------------------- | ---------------------- | ----------------------------------------------- |
| Conta bancária               | `BankAccount`          | Where the user keeps money                      |
| Conta fixa                   | `RecurringBill`        | Rent, electricity and other repeating bills     |
| Conta do usuário             | `User`                 | The login identity                              |
| Lançamento                   | `Transaction`          | Money in, money out or a transfer               |
| Fatura                       | `CreditCardStatement`  | A credit card billing cycle                     |
| Parcelamento                 | `InstallmentPurchase`  | A purchase split across statements              |
| Plano (meta)                 | `FinancialPlan`        | A goal broken into steps, such as paying a debt |
| Plano Grátis / Plus          | `BillingPlan`          | What the user pays Juízo for                    |
| Assinatura (Netflix e afins) | `TrackedSubscription`  | A subscription the user tracks in Juízo         |
| Assinatura do Juízo          | `BillingSubscription`  | The user's subscription to Juízo                |
| Financiamento / empréstimo   | `Loan`                 | A debt to an institution                        |
| Dívida com pessoa            | `PersonalDebt`         | A debt to a person the user knows               |
| Automação                    | `Automation`           | A rule that creates entries or sends alerts     |
| Crédito de IA                | `AiCredit`             | The unit consumed by Ju                         |
| Raio-X                       | `FinancialCheckup`     | The summary that closes the onboarding          |
| Saúde financeira             | `FinancialHealthScore` | The 0 to 100 score                              |
